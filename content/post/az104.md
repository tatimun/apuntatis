# Implementación de aplicaciones web de Azure App Service
## Azure App Service

Azure App Service es una plataforma administrada para simplificar la implementacion y el escalado de aplicaciones web, backend, movile y API. 
Permite lenguajes como .NET, Java, Node.js, Python o PHP y despliega en entornos Windows o Linux, tambien si tenes un contenedor podes usarlo para desplegar en un tu contenedor customizado

Permite escalar hacia arriba o abajo:
- Verticalmente: Agrega numero de nucleo o cantidad de memoria RAM
- Horizontalmente: Capacidad para aumentar o disminuir numero de instancias de la maquina que ejecuta la app web

### ¿Deployment Slot? ¿Que es?
Es una ranura con otra copia de tu app corriendo al mismo tiempo pero sin afectar tu productivo.
Es como tener un ambiente desarollo o homologacion y podes desplegarla en el mismo servicio sin tener que levantar otro servicio aparte 

Podes subir una nueva version y probarla sin romper nada! Y encima te genera una URL para probarlo aparte de tu produccion

OJO! No se intermcabia toda la config:
- Secrets
- Connection Strings
- App Settings

No se comparten para no apuntar a misma DB por ejemplo


### App service en Linux
Podes utilizar contenedores o una base de Linux, admite muchas imagenes integradas espeficiadas. Los lenguajes adminitos: Net, Java, NodeJS Python y PHP 

Para verificar

    az webapp list-runtimes --os-type linux

No se admite en el plan de tarifa compartido
Azure Portal solo muestra las caracteristicas que funcionan actuales para apps linux.
